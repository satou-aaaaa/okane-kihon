# お金のきほん

分割払い・リボ払い・利息・税金の場面を見て、「最後にいくら払う？」を4つから選ぶ1日5問のゲーム。事前の知識なしで遊べ、答えのあとに計算のしかたと内訳（元金と手数料など）が出ます。押すだけ、時間制限なし。

- 遊ぶ: <https://satou-aaaaa.github.io/okane-kihon/>
- 今日の5問（やさしい2・ふつう2・むずかしい1）はだれでも同じで1日1回。上級（むずかしい3問・ヒントなし）、練習（何度でも）、とことん（好きなだけ。まちがえても続く）、解いたしくみが集まる「しくみ帳」があります。
- 18種類：サブスクの1年分・消費税（8%と10%）・1年の利息・単利・貯金の月数・複利・分割払い・リボの手数料・利息の上限（利息制限法）・72の法則・物価・利息の税金・リボの合計と月数・積み立て・リボの支払いを2倍に・分割とリボの比較・借り入れの利息。
- 選び肢には、よくある思いちがい（単利で計算する・手数料を忘れる・もう一方の税率）が入っています。
- 見やすさの設定（読みやすい文字・色の見分け・動きを減らす・読み上げ）と、記録を別の端末へ移す「引き継ぎ」があります。

## 計算のしかたと出どころ

- 分割払いは元利均等（毎月同じ額）、リボ払いは元利定額（毎月同じ額・手数料こみ。残高×年率÷12を毎月、円未満切り捨て）で計算します。実際のカード・ローンは日割りや支払い日などで少しちがう金額になります。率は問題のための例です。
- 利息制限法の上限金利（10万円未満20%・100万円未満18%・100万円以上15%）：[日本貸金業協会](https://www.j-fsa.or.jp/association/money_lending/law/maximum_interest_rate.php)
- リボ払いのしくみと注意：[J-FLEC（金融経済教育推進機構）](https://www.j-flec.go.jp/public/learn/glossary/r_revo_barai/)
- 72の法則：[J-FLEC](https://www.j-flec.go.jp/public/learn/glossary/n_nanajunino_hosoku/)
- 預金の利息の税金（15.315%と住民税5%）：[国税庁 No.1310](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1310.htm)
- 消費税の軽減税率（8%）：[国税庁](https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/01.htm)。問題は2026年11月の税率で作っています（2027年4月から2年間、食べ物の税率を下げると国税庁が知らせています）。

このゲームはお金のしくみを知るためのもので、特定の商品をすすめたり、投資の助言をしたりするものではありません。

## 記録と通信

記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を読み込むとき、まだ端末に保存が無ければ Google に IP アドレスが届きます。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（問題と答えは入りません）。
